# 示例模板

`lupus-v6.json` 是“那个没系完的结”的可编辑医学故事草稿：20镜、25fps、60秒、9:16。它演示需求、人物/道具、事实依据、素材槽、镜头衔接和医生同步路线，并不包含新成片、真实医生照片或已经通过的声音。

模板有52个专属槽（其中20个是底片输出）、12个独立网络参考图，共64条资产。前镜依赖绑定实际合格产物；声画分离制作的医生镜头必须先验声音再驱动口型。载入模板不代表批准生成或扩大费用。

资源导入器读取 `lupus-v6.assets.json`，按相对路径加载、校验SHA-256并注册到新项目。源码包中的所有参考图逐件许可见 `assets/CREDITS.json`；保留署名与许可证链接。病灶图仅作教学形态审稿，库存诊室人物不是本片指定医生或女主。真实制作必须另行绑定专属身份与对应素材。

没有打包原医生照、资料包、私人文件路径、接口密钥、旧项目任务回执或旧生产发布脚本。新Mac无需存在原项目目录。
