# 视频模型切换与恢复

`VIDEO_MODEL` 单独选择视频及原生声音模型；为空时继续使用 `SEEDANCE_MODEL`。同一已配置的 `SEEDANCE_BASE_URL` / `SEEDANCE_API_KEY` 接入 EasyRouter，不在浏览器保存供应商密钥。

支持 `veo-3.1-generate-001`、`veo-3.1-fast-generate-001`、`veo-3.1-lite-generate-001`。Veo 适配器使用供应商的顶层字段协议，1080p、8秒、原生声音、9:16或16:9；生成素材时长与镜头时长分别记录。仅发送首帧，尾锚图不属于实际输入。并非每种列出的模型都经过真实调用验收。

参考协议：<https://docs.easyrouter.io/zh/docs/api/ai-model/videos/veo31>。返回媒体链接可能指向另一个需鉴权的域名；Veo 下载使用已配置同源 `/videos/:id/content`。下载失败只恢复原任务下载，不再次提交生成。

每个新视频／声音任务保存 `providerSpec`，包含模型、协议、来源、参考方式及输出策略并参与幂等哈希。未提交任务遇到配置变化时拒绝执行；已有供应商 ID 的任务仍按其原模型续查。旧版未提交且没有快照的任务需取消后创建新任务。受理不明仍保留 uncertain，不自动重投。

上游非成功响应最多解析16KiB JSON，只记录白名单错误码、类型及请求ID；不把任意错误正文、提示词、URL或凭据写入公开任务错误。历史仅保存HTTP状态的错误不能追溯推断原因。

## 本地媒体与图片兼容

管理员可通过现有产物导入接口登记在外部完成的真实视频。系统保存真实本地完成任务、文件哈希和 `manual-import` 来源，默认待审核；不会伪造供应商调用、模型回执或自动批准。原视频生成回执应在私有执行记录中保留。

本次提示词编译修正将“素材必须无人”等约束留在对应素材审核，不再作为整个真人镜头的指令。旧分镜图不会自动视为新编译版本的产物。`production-images/requalify` 仅允许管理员明确复核既有本地批准／采用图：完整本体、原图字节、两种绑定及父图均须一致，保留所有旧来源哈希。内容或父图修改不能通过这个接口消除审核失效。

声音超出镜头时长时，先听原声，再明确选择完整句子的区间并生成新候选；不能自动剪断、加速。裁剪接口及重新听审／口型制作流程见 [HANDOFF.md](HANDOFF.md)。

## 2026-10-11 真实验证界限

标准 Veo 3.1 单次首帧请求成功，源视频8秒、1080×1920、24fps、AAC48kHz立体声。生成视频和中文原声均存在；一处返回链接401通过同源内容下载恢复，未重投。自动转写定位首句结束约3.22秒，超过原定3秒；动作结束状态也需人工审核。此结果不是完整60秒影片通过，不代表 fast/lite 或 fal 口型真实验收完成。具体身份图片、回执、任务ID、账户日志及私有工程不包含在源码交付中。
